# Thư mục thực hành · Claude Thực Chiến

Toàn bộ dữ liệu trong thư mục này là **dữ liệu giả**, dựng theo bối cảnh một công ty phân phối bảo hiểm phi nhân thọ qua ứng dụng di động. Tên công ty ("Bảo Nhanh"), khách hàng, nhân viên, đại lý và đối tác đều là **hư cấu**.

Cách dùng: mở ứng dụng Claude trên máy tính → thẻ **Code** → chọn thư mục `hoc-claude-code` này làm nơi Claude làm việc.

| Thư mục | Bên trong | Dùng ở |
|---|---|---|
| `tai-lieu/` | 3 biên bản họp (Word) | Bài M3, 02, 06, 09 |
| `01-ban-hang/` | 4 file Excel doanh thu phí bảo hiểm tháng 7–10/2026, cố ý để "thô" | Việc 1 · Bài 08 |
| `02-ban-tin/` | Để trống, nơi lưu bản tin buổi sáng | Việc 2 · Bài 15 |
| `03-website/` | Để trống, nơi dựng website | Việc 3 · Bài 16–18 |
| `.claude/skills/phong-van-website/` | Skill phỏng vấn để làm website (thư mục ẩn) | Bài 16 |

Lưu ý: đặt thư mục ở nơi có tên **không dấu, không khoảng trắng** (ví dụ `Documents/hoc-claude-code`).
